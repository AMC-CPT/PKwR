# 반코마이신 TDM — 사용자 안내

이 도구는 환자의 **투여·혈중농도 이력**을 이용해 개인 약동학(PK) 파라미터를 추정하고,
목표 일일 AUC에 맞춘 **다음 용량**과 정상상태 최고/최저 농도, 예측 그래프를 제시합니다.
결과는 **임상적 판단을 보조**하기 위한 것으로, 최종 처방 결정은 담당 의료진의 책임입니다.

---

## 1. 시작하기 (3단계)

1. **Population model** 선택 — `AMC`(3-ETA, 비례오차) 또는 `Inje`(4-ETA). 모델이 하나뿐인 화면에서는 선택 항목이 표시되지 않습니다.
2. **Upload CSV** — NONMEM 형식의 환자 파일(한 명)을 올립니다.
3. 자동으로 개인 파라미터가 추정되고 **AUC 기반 권고 용량**과 그래프가 나타납니다. 필요하면 좌측의 *Proposed next regimen* 값을 바꾸고 **Draw Graph**를 눌러 다시 그립니다.

---

## 2. 입력 파일 형식

CSV(쉼표 구분). **최소 필수 열**: `ID, TIME, AMT, RATE, DV, CLCR`.

| 열 | 의미 | 비고 |
|----|------|------|
| `ID` | 환자 식별자 | **한 파일에 한 명만** (여러 ID가 섞이면 거부) |
| `TIME` | 시각 | 숫자(시간) 또는 시계시각(`08:30`)+`DATE`/`DAT2` 열 |
| `AMT` | 투여량 (mg) | 투여행은 `AMT>0` 이면서 `RATE>0` 이어야 함 |
| `RATE` | 주입속도 (mg/h) | `AMT/RATE` = 주입시간(Tinf) |
| `DV` | 측정 농도 (mg/L) | 관측행만 값, 투여행은 비움 |
| `CLCR` | 크레아티닌 청소율 | 없으면 `AGE,BWT,SCR`로 Cockcroft-Gault 산출 |
| `MDV`, `EVID` | (선택) | 0=관측, 그 외=투여/무측정 |
| `II`, `ADDL` | (선택) | 반복투여 간격/추가 횟수 |
| `SEX` | (선택) 성별 | **`0` = 여성, `1` = 남성** (다른 값은 거부). C-G 계산 시 여성에 0.85 적용 |
| `AGE,BWT,SCR,ALB` | (선택) 공변량 | `CLCR` 산출·표시에 사용 |

- **결측 표기**: `.`, 빈칸, `NA` 모두 결측으로 처리됩니다.
- **날짜 형식은 반드시 `YYYY-MM-DD` (예: `2021-11-13`)** 만 허용합니다. 일/월 순서가 모호한
  `MM/DD/YYYY`·`DD/MM/YYYY`·`DD-Mon-YYYY` 등은 시간 순서를 잘못 배열할 위험이 있어 **거부**됩니다.
- `DATE`(또는 `DAT2`) + 시계시각(`HH:MM`)을 쓰면 첫 기록을 0시로 하여 시간(h)으로 환산합니다.
- **성별 코딩: `SEX=0` 여성, `SEX=1` 남성.**
- 열 이름 별칭 자동 인식: `CLCR`←`CRCL/CCR2/CCR`, `BWT`←`WT/WEIGHT`, `SCR`←`CREAT` 등.
- **CLCR 일부 결측**: 마지막 측정값을 이월(LOCF)하여 채웁니다.

---

## 3. 화면 구성

**좌측 패널**
- *Population model*: 모집단 모델 선택.
- *Upload CSV*: 파일 업로드.
- *Proposed next regimen*: 그래프에 그릴 **가상의 다음 처방** — 시각/용량/속도/간격(II)/추가횟수(ADDL). 업로드 시 권고값으로 자동 채워집니다.
- *Draw Graph*: 좌측 값으로 예측 곡선을 다시 그림.
- *Time range*: 그래프 x축(시간) 범위.

**탭**
- **Data and Graph**: 예측 곡선과 측정점, 개인 IPRED 표, AUC 권고표, 제안 처방 지표.
- **Input Data**: 업로드한 원본 표(그대로).
- **PK Parameter**: 개인 ETA와 추정 파라미터(CL/V1/V2/Q).
- **도움말**: 이 문서.

**그래프의 선**
- ● 점: 측정 농도(DV).
- 실선: 개인 예측(IPRED).
- 빨강 점선: 예측의 **신뢰구간(±1.96 SE)** — 추정 불확실성.
- 파랑 점선: **예측구간(±1.96 SD)** — 다음 측정이 놓일 범위(잔차오차 포함).
- 가로 점선: 5·15·25·35 mg/L 참고선.

---

## 4. 결과 해석

- **AUC-guided recommendation**: 목표 일일 AUC(기본 410 mg·h/L)를 맞추는 1회 용량(10 mg 단위 반올림)과 그때의 정상상태 Css,max / Css,min.
- **Last dosing interval τ**: 이력에서 추정한 최근 투여간격을 표준값(8/12/24/36/48 h) 중 가까운 값으로 스냅한 것. 권고 용량은 τ에 비례하므로, 실제 계획 간격과 다르면 좌측 *II*에 원하는 간격을 넣고 확인하세요.
- **Proposed regimen (제안 처방)**: 좌측 입력값으로 계산한 지표. 좌측 값이 그래프에 반영된 처방과 다르면 표 위에 *(Draw Graph 눌러 반영)* 안내가 표시됩니다.
- **PK Parameter**: `CL`은 마지막 CLcr(150에서 상한)로 스케일된 개인 청소율입니다.

---

## 5. 경고 배너

- **측정이 1건뿐**: 개인 추정치가 모집단 사전분포에 크게 의존합니다. 파라미터·예측을 신중히 해석하세요.
- **큰 잔차(RMSE > 8 mg/L)**: 이상치이거나 채혈/투여 시각 오류일 수 있습니다. 원자료를 확인하세요.

---

## 6. 자주 나오는 오류와 해결

| 메시지 | 원인 / 해결 |
|--------|-------------|
| *Dose record(s) at TIME = … have an amount without a matching infusion rate* | 투여행에 `RATE`가 비었거나 0. 모든 투여는 `AMT>0` **그리고** `RATE>0` 필요. |
| *This tool fits ONE patient at a time …* | 파일에 여러 `ID`. 한 명씩 분리해 업로드. |
| *No observed concentrations (DV) found* | 관측행(`MDV=0`)의 `DV`가 없음. |
| *Model needs CLCR (or AGE, BWT, SCR …)* | 신기능 정보 부족. `CLCR` 또는 `AGE,BWT,SCR` 제공. |
| *For repeated doses, the infusion duration … must be shorter than the interval* | 반복투여에서 `AMT/RATE ≥ II`(주입이 간격보다 김). 용량/속도/간격 조정. |
| *Additional doses must be a whole number between 0 and 60* | `ADDL` 은 0–60 사이 정수. |
| *DATE must be ISO format YYYY-MM-DD …* | 날짜를 `YYYY-MM-DD`(예: `2021-11-13`)로 변경. 슬래시·일/월 순서 형식은 불가. |
| *SEX must be coded 0 = female or 1 = male* | `SEX` 값이 0/1이 아님. 0=여성, 1=남성으로 코딩. |

---

## 7. 한계와 주의

- 소수(특히 1~2건) 시료에서는 추정치가 모집단 사전분포에 의존합니다.
- 투여간격은 표준값으로 **스냅**되므로, 비표준 간격에서는 좌측 *II*로 직접 지정해 확인하세요.
- 겹치는 주입(주입시간 ≥ 간격)은 정확히 모델링되지 않아 **거부**됩니다.
- 예측구간 하한이 음수가 될 수 있어 그래프에서는 0으로 잘라 표시합니다(농도는 음수 불가).
- 이 도구는 **의사결정 보조**입니다. 반드시 임상 상황과 함께 판단하세요.
