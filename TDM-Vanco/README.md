# Vancomycin TDM (Shiny)

2-구획 정맥 주입 모델 기반 반코마이신 TDM 도구. 환자의 투여·농도 이력(NONMEM 형식 CSV)을
업로드하면 개인 PK 파라미터를 empirical-Bayes(MAP)로 추정하고, 목표 일일 AUC(기본 410 mg·h/L)에
맞춘 1회 용량과 정상상태 Cmin/Cmax, 예측구간 그래프를 제시한다.

![앱 화면](screenshot.png)

*화면은 `tests/fixtures/synthetic_patient.csv`(합성 자료)를 넣은 것이다. 실제 환자 자료는 이
저장소에 없다.*

설치 없이 브라우저에서 바로 보려면 <https://amc-cpt.github.io/PKwR/> 를 열면 된다
(shinylive/WebAssembly 판이라 업로드한 파일이 브라우저 밖으로 나가지 않는다).

## 파일 구조

| 파일 | 역할 |
|------|------|
| `TDMLIB3.R` | **검증된 수치 엔진**: 전방모델(`PredVanco`), MAP 추정(`EBE`), 예측구간(`calcPI`), AUC 용량(`aucDose`/`ssMetrics`), CSV 수집(`prepTDM`). 원 논문(Inje 모형, 56명) NONMEM EBE를 재현. |
| `models.R` | 모집단 모델 **단일 출처**: `PARSETS`(AMC 3-ETA / Inje 4-ETA), `AUC_TARGET`, `TINF`. (이전엔 OMEGA 행렬이 Start3·Start4에 각각 손으로 복사돼 있었음 → 오타 위험 제거.) |
| `tdmApp.R` | **앱 본체(팩토리)**: `tdmApp(models, selected, title, auc_target, tinf, help_md)` 하나로 UI+서버를 생성. 모델이 1개면 선택 라디오를 숨김. **도움말 탭** 포함. |
| `app.R` | 표준 진입점. `shiny::runApp("TDM-Vanco")` 로 실행(권장). AMC+Inje 선택형. |
| `Start4.R` | 얇은 wrapper: AMC+Inje 선택형(구 Start4 동작). |
| `Start3.R` | 얇은 wrapper: Inje 단일 모델(구 Start3 동작, 라디오 없음). |
| `RunMe.R` | 런처. `runApp` 을 **앱 폴더**로 지정. |
| `help_user.md` | **사용자 안내**: 앱의 도움말 탭에 렌더(commonmark). |
| `ADMIN.md` | **관리자 매뉴얼**: 설치·실행·모델 추가·회귀·문제해결. |
| `tests/` | 합성 데이터 기반 회귀 테스트(아래). |


## 이번 개선에서 무엇이 바뀌었나

**핵심 보장: 유효한 입력에 대한 계산 결과(EBE·SE·COV·IPRED·예측구간·AUC/용량 권고)는 리팩터 전후로
비트 단위 동일하다.** 5개 실제 데이터 × 2모델을 golden 회귀로, 앱 레벨 출력을 `shiny::testServer` 로
각각 max|delta| = 0 으로 확인함.

### 1. 중복 제거 (동작 불변)
- `Start3.R`/`Start4.R` 의 ~90% 중복(서버 전체, UI, OMEGA 행렬 사본)을 `tdmApp.R` 팩토리 + `models.R` 로 통합.
  두 진입 파일은 각각 한 줄 호출로 축소.
- 엔진 로더(경로 fallback)와 PK 파라미터 표 계산을 한 곳으로 통일(`indivPK`).

### 2. 안전한 강건성/UX 수정 (유효 입력의 숫자는 불변, 깨지던 입력만 고침)
- **용량 무음 소실 방지**: 용량행(AMT>0)에 RATE가 없거나(또는 그 반대) 하면 조용히 삭제되던 것을 명확한 오류로 거부.
- **단일 환자 강제**: 여러 ID가 섞인 파일을 하나의 타임라인으로 잘못 적합하지 않도록 거부.
- **결측 CLCR 복구**: 일부 행의 CLCR가 비면 마지막 측정값을 LOCF(+선두 back-fill)로 채움(그리드 처리와 동일 정책). 완전한 CLCR 파일은 무변화.
- **AUC 권고**: 마지막 *유효* CLcr 사용(마지막 행이 비어도 NA 권고가 나오지 않음). `lastTau` 대체값을 UI 입력이 아닌 고정값(12)으로 → 권고가 재현 가능.
- **UI**: 모델 전환 시 사용자가 손으로 넣은 regimen을 보존(편집 전 전환은 새 모델 권고로 갱신); x축 슬라이더를 실제 곡선 범위로 구동(빈 II/ADDL에도 안 깨짐); 반복투여의 겹치는 주입(Tinf≥τ) 거부; ADDL 정수·0–60 검증; 예측구간 하한을 표시상 0으로 클램프(음수 농도 방지); 좌측 입력과 그래프가 다르면 "(Draw Graph 눌러 반영)" 표시.
- **날짜 형식 ISO 전용**: `YYYY-MM-DD` 만 허용, 모호한 일/월 순서 형식(`MM/DD/YYYY` 등)은 거부. 참조 코호트 364 파일 전부 ISO라 무변화.
- **성별 코딩 명시**: `SEX` 는 `0`=여성 / `1`=남성으로 명시·검증(다른 값 거부). C-G 계산 시에만 사용되며 어느 가정을 썼는지 경고로 표면화. `CLCR` 열이 있는 파일은 무영향.
- **RunMe.R**: 실제 리포 폴더로 수정, 포트 충돌/도달 불가 라인 정리.

### 3. 증명 가능하게 무해한 엔진 하드닝
- `indivPK` 에도 CLcr 150 cap 적용(모든 호출부가 이미 cap → 결과 불변, 내부 일관성만 향상).
- `EBE` 의 잔차분산 `Vobs` 를 `ObjEta` 와 동일한 형태로 통일(현 두 모델은 대각 SIGMA라 결과 비트 동일).

### 4. AMC 사전투여-0 크래시 수정 (전수 회귀 완료)
- **문제**: AMC는 가법오차가 0(순수 비례오차)이라, 첫 주입 이전(예측농도 0)에 측정 시료가 있으면
  목적함수가 `log(0)+Ri²/0 = NaN` 이 되어 **기본 모델(AMC)에서 추정이 즉시 실패**했다(Inje는 안전).
- **수정**: `ObjEta` 와 정보행렬에서 **잔차분산이 0(비양)인 관측을 제외**. 그런 점은 예측이 ETA에
  무관(0)해 정보량이 0이므로, 제외해도 추정값이 바뀌지 않으면서 목적함수가 유한해진다.
- **전수 회귀 증거**:
  - 참조 코호트 **전수 × 2모델 전부 비트 단위 동일**(max|delta|=0). 기존 유효 입력은 변하지 않았다.
  - 별도로 구성한 사전투여-0 케이스: 원본=크래시 → 수정=정상 fit이며, "사전투여 점 포함" fit == "제외" fit(delta=0)로 무정보 점을 올바르게 제외함을 확인.
  - Inje EBE가 NONMEM 배치 참조와 356명 전원 일치(반올림 오차 5e-6).
  - `tests/fixtures/synthetic_predose_amc.csv` 로 이 수정을 회귀에 고정.

## 회귀 테스트

실제 환자 데이터는 커밋하지 않고, `tests/fixtures/` 의 **합성(가짜) 환자**로 수치를 고정한다.

```r
Rscript tests/regression.R make    # 기준선(golden_baseline.rds) 생성/갱신
Rscript tests/regression.R check   # 현재 출력과 비교, 차이가 있으면 비정상 종료
```

`TDMLIB3.R` 이나 `models.R` 을 수정한 뒤 `check` 가 통과하면 검증된 숫자가 바뀌지 않았음을 의미한다.
(실제 데이터로 검증하려면 `tests/fixtures/` 에 CSV를 추가하고 `make` 로 기준선을 다시 만든 뒤 커밋하지 말 것.)

## 저자 결정 반영 결과

리뷰에서 표시했던 항목들에 대한 저자 결정과 처리 상태.

| 항목 | 결정 | 처리 |
|------|------|------|
| AMC 사전투여-0 크래시 | 수정 | ✅ 적용 (§4, 356×2 전수 회귀 비트 동일) |
| `lastTau` 투여간격 스냅 | **스냅된 τ 사용, 그에 따른 용량 권고** | ✅ 현행 유지(스냅 τ→용량). 도움말에 스냅 설명 명시 |
| 겹치는 주입(Tinf≥τ) | **금지 유지** | ✅ 현행 유지(앱이 거부) |
| 날짜 형식 | **`YYYY-MM-DD` 만 허용** | ✅ 적용(다른 형식 거부) + 도움말 명시 |
| 성별 코딩 | **명시** | ✅ `SEX` 0=여성/1=남성 명시·검증 + 도움말 명시 |
| 엔진 scratch env `e` 클로저화 | **적용** | ✅ `EBE`가 목적함수를 지역 클로저로 생성(전역 가변 env 제거, 재진입 안전). 356×2 비트 동일 |

> 위 변경은 모두 참조 코호트 전수 × 2모델에서 **비트 단위 동일**함을 재확인함
> (날짜·성별 검증은 깨지던/모호하던 입력만 거부하며, 유효 입력의 숫자는 불변).

**남은 선택 항목**: 겹치는 주입의 정확한 엔진 모델링(현재는 금지로 충분). 변경한다면
`tests/regression.R` + 전수 회귀로 전/후를 대조할 것.
